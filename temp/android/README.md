# Block Boost Musique de fond 0.15.0 — APK expérimentale

Cette APK debug conserve les 21 effets sonores, et ajoute la musique de fond MP3 de Fab en boucle, réduite pendant FX et voix.
Elle s'installe séparément des laboratoires 0.1 à 0.6 ; sauvegardes indépendantes.
Cette APK complète intègre 21 sons synchronisés dans le jeu, sans audio autonome. Aucun merge main ni publication Google Play.
