# Block Boost Lumières 0.6.0 — APK expérimentale

Cette APK debug suspend temporairement les voix et ajoute une grille arc-en-ciel lors des combinaisons, avec haptique progressive.
Elle s'installe séparément de Block Boost 0.1.0, Émotion 0.2.0, Bonus 0.3.0 et Audio 0.4.0 ; sauvegardes indépendantes.
Aucune voix jouée, aucun merge main, aucune publication Google Play.
